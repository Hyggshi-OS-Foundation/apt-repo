Manual
1
Add GPG key
curl -fsSL https://hyggshi-os-foundation.github.io/apt-repo/hyggshi-archive-keyring.gpg | sudo gpg --dearmor -o /usr/share/keyrings/hyggshi-archive-keyring.gpg
2
Add sources.list entry
echo "deb [signed-by=/usr/share/keyrings/hyggshi-archive-keyring.gpg] https://hyggshi-os-foundation.github.io/apt-repo stable main" | sudo tee /etc/apt/sources.list.d/hyggshi.list
3
Update and install
sudo apt update && sudo apt install nexfetch
